Dynamic Configuration

This gateway supports dynamic configuration through request headers. You can specify:

  • Provider: Which AI provider to use
  • API Key: Your API key for the provider
  • Base URL: Custom endpoint (optional)
  • Provider-specific settings: Additional configuration

cURL Examples

1. Simple OpenAI Request
curl -X POST http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -H "x-portkey-provider: openai" \ -H "Authorization: Bearer YOUR_OPENAI_API_KEY" \ -d '{ "model": "gpt-4", "messages": [{"role": "user", "content": "Hello"}] }'
2. Anthropic Request
curl -X POST http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -H "x-portkey-provider: anthropic" \ -H "Authorization: Bearer YOUR_ANTHROPIC_API_KEY" \ -d '{ "model": "claude-3-sonnet-20240229", "messages": [{"role": "user", "content": "Hello"}] }'
3. Google Gemini Request
curl -X POST http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -H "x-portkey-provider: google-gemini" \ -H "Authorization: Bearer YOUR_GOOGLE_API_KEY" \ -d '{ "model": "gemini-pro", "messages": [{"role": "user", "content": "Hello"}] }'
4. JSON Configuration
curl -X POST http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -H "x-portkey-config: {\"provider\":\"openai\",\"api_key\":\"YOUR_KEY\",\"base_url\":\"https://api.openai.com\"}" \ -d '{ "model": "gpt-4", "messages": [{"role": "user", "content": "Hello"}] }'
